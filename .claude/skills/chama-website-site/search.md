# Search and sharing

- Search Console "not indexed" rows that are fine: *Page with redirect* (`www.` and `http://` variants), *Alternate page with proper canonical tag* (old addresses before they became redirects), *Not found (404)* for a literal `https://chamainteligente.com/*` Google picked up from nowhere, and *Excluded by 'noindex' tag* for `/agent`. That page has been noindex on purpose since it was made: it is the full-screen chat with no text of its own, the homepage already carries the flame, and indexing it would put an empty page in competition with `/` for the brand name. Google found it through the "Start a conversation" links and emailed about it on 2026-10-22. Leave it noindex and don't click Validate fix. The row that matters is a sitemap page under *Discovered, currently not indexed*. Fix it with URL Inspection, then Request indexing.
- Use `validator.schema.org` for JSON-LD. Google's Rich Results Test has returned server errors here, and a failure there says nothing about the page.
- Messengers cache a link preview by URL for a long time. A changed sharing card ships under a new dated filename (`og-YYYY-MM-DD.png`), never over the old one, and the old file stays for links already sent.
- When a change is meant to leave the design untouched, prove it: serve the old and new versions locally, screenshot both full page at desktop and mobile widths, and compare.
- Software and coaching carry equal weight, and a summary built from any machine-facing text must name both: the meta, og and twitter descriptions on `/` and `/simple`, the `llms.txt` summary line, and the `llms-full.txt` header. A test in `test/pages.test.js` guards the first two. The home page body talks only about software, so these descriptions are where coaching reaches a link preview. When a page's copy changes, re-read `llms-full.txt` against it, because it drifts quietly (it lost the home page's reordering and the removed "Also" line for two weeks in 2026-10).
- People linking to us get the logo from the media kit at `/brand` (`brand/index.html`, files in `brand/kit/`), and their agents get the direct file URLs from `llms.txt`. Don't rename a kit file: other sites hotlink them. If the mark changes, run `brand/mark/build-mark.py` and then `sh brand/kit/build.sh`, which re-renders the logos with Chrome and rebuilds the zip. A page at `brand/index.html` serves at `/brand` even though `brand/` also holds the raw assets.
