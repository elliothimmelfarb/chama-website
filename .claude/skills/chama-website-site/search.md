# Search and sharing

- Search Console "not indexed" rows that are fine: *Page with redirect* (`www.`, `http://`, and since 2026-11-16 `/built`, `/clients` and `/simple/*`), *Alternate page with proper canonical tag* (old addresses before they became redirects), *Not found (404)* for a literal `https://chamainteligente.com/*` Google picked up from nowhere, and *Excluded by 'noindex' tag* for `/agent`. That page has been noindex on purpose since it was made: it is the full-page chat with no text of its own, every page already opens the chat, and indexing it would put an empty page in competition with `/` for the brand name. Google emailed about it on 2026-10-22. Leave it noindex and don't click Validate fix. The row that matters is a sitemap page under *Discovered, currently not indexed*. Fix it with URL Inspection, then Request indexing.
- Use `validator.schema.org` for JSON-LD. Google's Rich Results Test has returned server errors here, and a failure there says nothing about the page.
- Messengers cache a link preview by URL for a long time. A changed sharing card ships under a new dated filename (`og-YYYY-MM-DD.png`), never over the old one, and the old file stays for links already sent.
- When a change is meant to leave the design untouched, prove it: screenshot the old and new versions at desktop and phone widths and compare, with the visual rig in `test/shots/`.
- Software and coaching carry equal weight, and every summary a machine reads must name both: `SUMMARY` in `site/machine.js` (the opening of `llms.txt` and `llms-full.txt`) and the home page's description in `site/content/en/home.js`, which is where coaching reaches a link preview of `/`. Before the rebuild, the hand-kept `llms-full.txt` drifted from the pages for weeks at a time; it is generated now, so a page's `text()` is the only thing to keep in step.
- People linking to us get the logo from the media kit at `/brand` (`site/pages/brand.js`, files in `brand/kit/`), and their agents get the direct file URLs from `llms.txt`. Don't rename a kit file: other sites hotlink them. If the mark changes, run `brand/mark/build-mark.py` and then `sh brand/kit/build.sh`, which re-renders the logos with Chrome and rebuilds the zip. The page is built to `brand/index.html`, which serves at `/brand` even though `brand/` also holds the raw assets.
- The public Hearth page (2026-10-22): LinkedIn would not save a link to a `noindex` page, which is why `/hearth` is an indexable public page about the room rather than the room itself. Since 2026-11-22 the room lives at hearth.chamainteligente.com, and `/hearth` is always the public page.
