Inline SVG exploration

Candidate editorial illustrations for chamainteligente.com. Every figure is pure inline SVG, no external requests, drawn in the page's own palette: ink hairlines, one ember accent, Helvetica. Each candidate is shown on the paper ground and the dark ground.

Section 1

AI changes more than the tools we use

The argument is chasing versus growing. Chasing is a sawtooth: learn a tool, the tool changes, start again near zero. Growing is compounding: each new capability lands on top of habits that persist. The diagram should carry that argument on its own.

1A. One shared axis

Both lines on the same field, so the gap between them is the whole story. The resets are dotted, like something falling away. Recommended.

1B. Small multiple

The Swiss comparison: same axis twice, side by side. Calmer, but the reader has to do the overlay themselves.

Section 2

The shape of the work

Regular one-to-one sessions where each conversation builds on the last. The figure should feel like a rhythm, not a program.

2A. Rising arcs

Six sessions on a baseline; each arc reaches further than the last because it starts from everything before it. The newest session is the ember one. Recommended.

2B. The staircase

Each tread begins exactly where the last ended: nothing resets, the work accumulates. Quieter, and it rhymes with the compounding curve in section 1.

Section 3

Agentic engineering training

Agents that plan, write, and verify code. The differentiator in the copy is the habit of evolving, so the figure emphasizes the return edge: what verification learned feeds the next plan.

3A. The loop

Plan, write, verify around a circle, with the verify-to-plan segment in ember: the part most teams skip. The flame sits at the center. Recommended.

3B. The pipeline with a return

A flatter, more architectural reading: a left-to-right pipeline with the ember return line underneath. Better if the section needs something short.

Section 4

Custom software for companies

The claim: the software a company uses defines its culture, so owning your software means deciding how you work. The figure has to make constraint versus fit visible without cartooning it.

4A. The box and the fit

Left: the company's true shape (dashed) forced into a box, flattened against its walls. Right: the same shape, with software drawn around it in ember. One idea, two panels. Recommended.

4B. The shape over time

Three moments: the company's shape changes, and the ember outline changes with it. Says the second half of the claim: owned software keeps fitting.

4C. The floor plan

Software as the building you work inside: a generic plan versus walls placed where this company actually moves, with the walked path dotted in ember. The richest metaphor, but the busiest drawing. Note: the doorway cuts are painted in the ground color, so this one is ground-specific rather than fully portable.

Section 5

Motif system from the flame

Small recurring marks built from the flame alone (the second path of the brand mark), so the fire recurs through the page at whisper volume. All of these reuse one 15 by 15 glyph.

5A. Centered divider

A hairline interrupted by the flame. For major breaks between acts of the page.

5B. Flame-tipped ember line

The page's existing ember-line motif, with the flame seated at its head. The ember segment becomes the flame's trail.

5C. Section mark and end mark

The glyph beside a section label, and the glyph closing a final paragraph, the way print closes an article.

5D. Asterism

Three flames as a print asterism, for a soft pause inside a long section. Use at 10 to 12 pixels, centered.
