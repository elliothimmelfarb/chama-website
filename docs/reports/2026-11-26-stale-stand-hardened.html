A page that grows while loading can no longer make the words slide

Yesterday's jitter came from Chrome keeping an old release point. I found exactly when Chrome does that, made the engine correct it, and added a check that grows every page on purpose to prove it.

When Chrome keeps the old release point

It only happens when the release point changes in the same frame the word started standing. One frame later, Chrome reads the change fine.

The new check, before and after the fix

The shots rig now loads every page, grows it 56px in its first frame, and compares where Chrome starts each stand with where the engine asked. Shown here for /engineering-department at 1440×900. Without the fix this size failed on /engineering-department, /coaching and /build in 3 runs out of 3, and your phone size failed in some runs.

Scrolling costs the same

The correction runs only when a measure moves a word, which never happens during a normal scroll (it ran 0 times in a full scroll). Style work per frame on /engineering-department, a 4000px touch scroll at 4× slower CPU, average of four runs:

Single runs on the phone swung between 38 and 42 on both builds, so these are the same. A still page did no style work on either.
