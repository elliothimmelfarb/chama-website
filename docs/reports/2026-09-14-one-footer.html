Decisions

The home page is "Software". The old list opened with the tagline "Software crafted for your company, and only yours" as unlinked text, so the one page you could not reach from the footer was the home page. The site has two offers, software and training, so the map names them side by side. If you would rather it said "Home", that is a one-word change in five files.

Company only. The GitHub icon was removed from the home footer on 2026-09-03 ("no name, no instruments") but survived on About and Training. The footer is the company's, so it is LinkedIn everywhere; your GitHub stays in the founder pill on /about.

Members stays off. The README records that the Members pill lives only on /training, beside the coaching it belongs to. The footer respects that.

No include step. Privacy and 404 keep their own inline styles, so the footer rules are copied into them. The README now says to change all five files together.

Not done

IndexNow was not pushed: a footer change is not a content change worth announcing, and the sitemap dates are unchanged.
